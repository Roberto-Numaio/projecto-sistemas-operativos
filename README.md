# 💻 Operating Systems Website

A multi-page website about **three operating systems**, created independently to practice HTML navigation, anchors, multiple pages, and basic CSS styling.

## 📖 About

This project was created as a personal practice project while learning HTML.

The main goal was to understand how different HTML pages can be connected and how users can navigate between them using **anchors and links**.

The website is divided into multiple pages, with an `index.html` serving as the main page and additional pages containing information about the different operating systems.

I also experimented with **basic CSS styling**, even though CSS was still a topic I was beginning to explore at the time.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* 🖥️ Information about three operating systems
* 🔗 Navigation using HTML anchors
* 📄 Multiple HTML pages
* 🏠 Main `index.html` page
* 🎨 Basic CSS styling
* ↔️ Navigation between different pages
